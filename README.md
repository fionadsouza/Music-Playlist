# Music-Playlist

## Description
Music Playlist Management System developed in C using a Doubly Linked List. Features include adding songs, displaying playlists, searching songs, deleting songs, and efficient playlist management through a menu-driven console application.

## Features
- Add songs to playlist
- Display playlist details
- Search for songs
- Delete songs
- Count total songs in playlist

## Technologies Used
- C Programming
- Doubly Linked List
- Dynamic Memory Allocation

## Learning Outcomes
- Understanding of linked list operations
- Dynamic memory allocation concepts
- Problem-solving and data structure implementation

## How to Run
1. Compile the program:
   gcc playlist.c -o playlist

2. Run the program:
   ./playlist
